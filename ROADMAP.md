# Roadmap

Open Workbench Studio is usable today (four programs, one UI, one MCP server). Ideas and planned work, roughly in
priority order — contributions are welcome:

1. **English UI** — the web UI and generator labels are Turkish only; move strings to a translation table and add
   English (and more languages).
2. **Printer profiles** — pick the bed size, filament slots and OrcaSlicer presets from a list instead of editing
   `printer.yaml` / `orca_project_settings.json` by hand.
3. **Screenshots and a short demo** in the README.
4. **More Maker generators** — cable organisers, drawer dividers, plant labels, wall hooks, coasters.
5. **Better offline use** — bundle three.js and the UI web fonts so the preview works without internet.
6. **Packaging** — a published wheel / container image and a one-line installer.
7. **Optional authentication** for running Studio on a shared network.
8. **Glow hardware** — measured values for common LED strips and controllers (the bundled ones are assumptions).
